## 2. 逐页设计

### P01 封面 — type: cover / role: hero
- layout：左侧 62% 文字区，右侧竖向深蓝窄块 + 几何细线
- 层级：主标「自学平台」58px → 英文副标 → 说明「警院 WeChat 全生态 · 五平台之一」→ 信息层（答辩人/指导教师/单位/日期）
- density：字数约 80 / 无图 / 留白 48%
- anti_pattern：禁止封面放数据指标；禁止照片背景；禁止三段式图标罗列

### P02 目录 — type: catalog
- 4 章：01 选题背景与平台定位（P03）/ 02 需求分析与功能设计（P06）/ 03 系统实现与验证（P11）/ 04 问题、结论与展望（P17）
- layout：左「目录 / CONTENTS」竖排，右侧章节清单行分隔细线
- anti_pattern：禁止"N 个章节"统计块、阅读顺序条、主线预告

### P03 章节扉页 01 — type: section
- 大字 01 + 「选题背景与平台定位」+ 一行关键词「资源分散 · 无前置校验 · 数据割裂」

### P04 现状痛点 — role: supporting
- 信息横幅：kicker「问题提出」+ 一句论断
- 2×2 矩阵：Ⅰ 资源分散 / Ⅱ 未学先做 / Ⅲ 过程无痕 / Ⅳ 数据割裂
- 底部结论条（浅蓝底）：判断句
- density：字数约 240 / 无图 / 留白 20%
- anti_pattern：禁止把四条痛点做成等宽四卡横排；禁止无判断的罗列

### P05 生态定位与职责边界 — role: supporting / visual_role: evidence
- 上半：五平台闭环链（论坛→自学→考试→工坊→广场），自学平台高亮
- 下半：左右两栏「本平台承担 5 项」/「明确不承担 5 项（含归属）」
- density：字数约 300 / 图示 1 / 留白 18%
- anti_pattern：禁止把闭环画成环形套娃图；禁止边界用红底大色块

### P06 章节扉页 02

### P07 业务目标与功能清单 — role: supporting
- 左 62%：G-01…G-06 表格（目标 / 度量 / V1.0 目标值）
- 右 38%：38 项功能分布条形（学生 10 / 教师 9 / 管理 10 / 开放 6 / 事件 3）
- 底部：一句判断（可验收性）
- anti_pattern：禁止表格整行填色；禁止把 38 项逐条列出

### P08 流程一 · 课程发布审核 — role: supporting
- 顶部：状态链 draft→pending→published→offline→archived，rejected 回流
- 下方左右：左侧发布前置条件与业务规则（4 条），右侧深蓝关键约束卡（一次通过率 ≥70%、涉密自查）
- anti_pattern：禁止状态机做成横向五个等大色块；禁止箭头压字

### P09 流程二 · 学习进度与完成判定 — role: supporting
- 5 步流程链：进入课时→心跳上报→进度聚合→完成判定→事件投递
- 下方：左「判定与续学规则」，右「可靠性设计（限流/幂等/outbox）」
- anti_pattern：禁止用饼图表达进度规则；禁止把 200ms 指标塞进正文段落

### P10 流程三 · 前置必修联动 — role: hero / visual_role: anchor
- 三泳道：实训工坊 / 自学平台 / 学生，三条编号动作串联
- 红色边界提示：不存 projectId、不感知项目状态、不参与准入判定
- anti_pattern：禁止泳道等宽等色导致主体不明；红色不超过 2 处

### P11 章节扉页 03

### P12 技术架构 — role: supporting / visual_role: evidence
- 四层堆叠：接入层 / 前端 / 服务 / 数据，右侧竖栏：认证中心 + 事件通道 + 下游
- anti_pattern：禁止把架构画成无层次的方块迷宫；禁止图标代替层级文字

### P13 权限与安全 — role: supporting
- 左：四层鉴权阶梯（页面 / 菜单按钮 / 接口 / 数据范围）
- 右：NFR-S 五条硬要求（会话、令牌、资源、上传、审计）
- anti_pattern：禁止把"前端隐藏"写成安全措施；禁止清单超过 6 条

### P14 非功能指标 — role: supporting
- 左 55%：性能指标表（8 行，场景/指标/口径）
- 右 45%：KPI 三联（LCP 1.5s / 进度上报 200ms / 500 并发）+ 可用性 99.9%
- anti_pattern：禁止用无刻度的柱状图伪造"性能对比"

### P15 落地验证 — role: hero / visual_role: anchor
- 左：环境表（组件 / 版本 / 选型理由 5 行）
- 右：KPI 三联（73 张表 / 9 门课程 / 28 个视频）+ 部署事实 3 条
- 底部口径说明：该环境为业务验证环境
- anti_pattern：禁止把真实部署数字与设计指标混排在同一组 KPI

### P16 实现效果 — role: supporting / visual_role: evidence
- 左 58% 大图（首页），右 42% 上下两图（课程详情 / 后台），各配一句说明
- anti_pattern：禁止三图等大平铺；禁止图下无说明

### P17 章节扉页 04

### P18 三个关键问题与对策 — role: supporting
- 三行表格式：问题 / 对策 / 结果，行间 1px 细线
- anti_pattern：禁止写成"经验总结"式空话；每条必须带具体约束或数字

### P19 结论、局限与后续 — role: supporting
- 左：3 条结论；右：3 条局限（诚实）+ 2 条后续
- anti_pattern：禁止把局限写成"时间有限"；禁止结论重复目录

### P20 封底 — type: ending
- 「请各位老师指正」+ 平台名 + 日期，无页脚
