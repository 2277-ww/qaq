# 前端「警院风格」主题改造说明

> 实施时间：2026-11-05　实施范围：课程平台前台（`/www/ctc`，HTTPS 443 唯一入口）
> 原则：**只改视觉，不改结构、不改内容、不改功能**

---

## 一、设计规范

### 1.1 主色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 藏蓝（最深） | `#08152A` | 页脚底色、页头渐变端点 |
| 藏蓝（主） | `#0B1F3A` | 页头主色、标题文字 |
| 藏蓝（中） | `#102A4C` | 页头渐变中段、卡片描边 |
| 藏蓝（亮） | `#16375E` / `#1D4773` | 按钮 hover、进度条、正文链接 |
| 警徽金（主） | `#C8A24A` | 分隔线、角标底、星级、hover 描边 |
| 警徽金（浅） | `#E8CF92` | 深底上的高亮文字 |
| 暗金（正文用） | `#7A5B1E` | 白底上的金色小字，保证 ≥4.5:1 对比度 |
| 页面底 | `#F4F6FA` | 叠 44px 淡网格纹理 |
| 描边 | `#DCE3EB` / `#C9D3DF` | 卡片、输入框 |

### 1.2 字体

- **标题 / 导航 / 按钮**：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", SimSun, Georgia, serif`
  —— 衬线体营造文件、文书的庄重感。
- **正文 / 数据**：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`
  —— 正文不用衬线，保证长文与小字号可读性。

### 1.3 象征元素

| 元素 | 实现位置 | 说明 |
| --- | --- | --- |
| 盾徽（五角星 + 盾形 + 垛口横线） | `partials/header.volt` 内联 SVG | 26×30，置于校徽铭牌左侧；纯线条描金，未使用任何官方徽标图案 |
| 校徽铭牌 | `theme-police.css` `.logo a` | 白色托底 + 金色双环，解决原蓝色 logo 压在藏蓝底上对比度不足 |
| 绶带 | `partials/footer.volt` + `.police-ribbon` | 页脚顶部居中的金色燕尾折带，挂盾徽与「明德 · 笃学 · 守正」 |
| 纪律线 | `.index-wrap .header::after`、`#header::before` | 区块标题下方的金线渐隐线；页头顶端 3px 金色渐变条 |
| 斜纹肌理 | `#header::after` | 115° 重复细斜纹，低透明度，模拟制服/文书纹理 |
| 网格底纹 | `body.main` | 44×44px 淡网格，呼应坐标纸/卷宗感 |

## 四、一并修掉的历史问题

改造过程中发现并修复了原主题在移动端的既有缺陷（非本次引入）：

1. `.layui-main` 固定宽 1250px 不响应 → 整页横向溢出。
2. `.course-card .cover img` 固定 275×155 → 窄屏封面撑破卡片。
3. `.course-meta` 三栏固定宽（270/580/340）→ 详情页信息挤压重叠。
4. `.filter-group` 固定 40px 行高 → 筛选条件换行后文字压叠。
5. `.search-form .query-input` 固定 696px → 搜索页横向溢出。
6. `#footer` 100% 宽 + 左右 padding 未设 border-box → 页面右侧多出 24px 空白。

## 六、回滚方法

```bash
# 1) 还原模板与样式
cp /root/ctc_theme_backup/views/main.volt      /www/ctc/app/Http/Home/Views/templates/main.volt
cp /root/ctc_theme_backup/views/partials/*.volt /www/ctc/app/Http/Home/Views/partials/
cp /root/ctc_theme_backup/css/*.css            /www/ctc/public/static/home/css/

# 2) 清模板编译缓存（务必保持 apache 属主）
rm -f /www/ctc/storage/cache/volt/*
chown apache:apache /www/ctc/storage/cache/volt
```

新增的 `theme-police.css` 不删也无影响——`main.volt` 还原后不再引用它。

---

## 七、运维注意

- **清 volt 缓存后必须 `chown apache:apache`**。php-fpm 以 `apache` 用户运行，若缓存目录属主变成 nginx，会立刻出现 `Volt directory can't be written` 并全站 302 到 `/error/500`（本次已踩过一次）。
- 修改 `theme-police.css` 后，需同步递增 `main.volt` 里的 `?v=` 版本号，否则客户端缓存不刷新。
- 静态资源版本号统一由 `config/config.php` 的 `static_version` 控制；本主题使用独立版本号，不受其影响。
