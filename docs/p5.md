# 6 数据需求

## 6.1 数据总体说明

本平台数据分为四类：**内容数据**（课程、章节、课时）、**学习数据**（课时进度、课程进度）、**个人数据**（笔记、收藏）、**治理与集成数据**（审核记录、事件发件箱、公开接口客户端、审计日志）。四类数据的生命周期与共享范围不同，须分别治理。

| 编号 | 实体 | 说明 | 主键 | 主要关系 |
|---|---|---|---|---|
| ENT-01 | course_category | 课程分类 | categoryId | 一对多 course |
| ENT-02 | course | 课程主数据 | courseId | 属一个分类；含多章节；责任教师为 userId |
| ENT-03 | course_chapter | 章节 | chapterId | 属一个课程；含多课时 |
| ENT-04 | course_lesson | 课时 | lessonId | 属一个章节与课程；类型为图文或视频 |
| ENT-05 | lesson_progress | 课时级学习进度 | progressId | userId + lessonId 唯一 |
| ENT-06 | learning_progress | 课程级学习进度 | progressId | userId + courseId 唯一 |
| ENT-07 | learning_note | 学习笔记 | noteId | 属一个用户，可关联课程与课时 |
| ENT-08 | course_favorite | 课程收藏 | favoriteId | userId + courseId 唯一 |
| ENT-09 | review_record | 审核与状态迁移记录 | recordId | 关联课程与操作人 |
| ENT-10 | course_completion_view | 完成状态投影 | userId + courseId | 由 learning_progress 派生，供公开接口查询 |
| ENT-11 | event_outbox | 事件发件箱 | eventId | 关联课程完成事实 |
| ENT-12 | open_api_client | 公开接口客户端 | clientId | 关联调用方平台 |
| ENT-13 | audit_log | 审计日志 | logId | 记录操作人与对象 |

实体关系要点：一个分类下可有多个课程；一个课程包含多个章节，章节包含多个课时；课时是学习的最小单位，进度以课时为事实、以课程为派生；审核记录按时间序列追加快照，不覆盖历史；完成投影表与主数据保持 1 秒内一致，仅用于对外查询，不作为业务判定依据。

## 6.3 通用字段与建模约定

| 约束项 | 规定 |
|---|---|
| 主键 | 业务表统一使用 VARCHAR(26) 的 ULID，禁止自增数字主键；对外接口只暴露 ULID |
| 时间字段 | 数据库统一存 UTC，接口输出转为 +08:00；每表至少包含 createdAt、updatedAt |
| 逻辑删除 | 内容类与个人类表使用 deleted 标记，查询默认过滤；审计与事件表不删除 |
| 冗余字段 | 允许为查询性能冗余少量字段（如 courseId、lessonCount），但冗余字段须有明确的同步机制与修复脚本 |
| 状态字段 | 一律使用 VARCHAR 存放大写蛇形值，不使用数字编码，避免字典漂移 |
| 枚举扩展 | 新增状态或类型须同步更新附录 A，禁止在代码中出现未登记的字面量 |
| 金额与积分 | 本平台不涉及金额、积分、学分字段 |
| 字符集 | utf8mb4，排序规则统一，避免大小写敏感差异导致唯一键冲突 |

## 6.4 数据保留与清理

| 数据类型 | 保留期 | 清理方式 |
|---|---|---|
| 课程与课时内容 | 长期保留，归档后只读 | 不物理删除；违规内容按快照留存后屏蔽 |
| 课时级进度 | 在校期间保留，毕业后归档 | 按学年归档至冷存储，保留查询能力 |
| 课程级进度 | 长期保留 | 不删除，完成记录是成长档案的依据 |
| 笔记与收藏 | 用户主动删除后逻辑删除，30 天后物理清除 | 定时任务清理 |
| 审核记录 | 长期保留 | 不删除 |
| 事件发件箱 | 成功投递后保留 180 天 | 定时归档，审计可查 |
| 审计日志 | ≥ 180 天 | 到期归档，不物理删除关键操作 |
| 接口调用日志 | 90 天 | 到期清理 |
