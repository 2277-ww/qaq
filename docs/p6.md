# 7 接口简述

本章为接口概要，用于说明接口划分、主要入参与出参要点。完整的字段级契约以 OpenAPI 定义为准，本章与契约不一致时以契约为准并回写本章。

## 7.1 通用约定

| 约定项 | 内容 |
|---|---|
| 路径前缀 | 内部接口 `/api/v1/`，对外公开接口 `/open/v1/`，两者物理隔离，不共用鉴权中间件 |
| 方法语义 | GET 查询、POST 创建与动作、PUT 全量更新、PATCH 局部更新、DELETE 删除；查询类禁止使用 POST（批量查询除外） |
| 鉴权 | 内部接口使用 SSO 访问令牌，置于 Authorization 头，Bearer 方案；公开接口使用客户端凭证换取令牌，置于 Authorization 头 |
| 响应结构 | 统一包裹 code、message、data、requestId、timestamp，见 2.4.1 |
| 分页 | page、pageSize 入参，page、pageSize、total、totalPages、list 出参，见 2.4.2 |
| 幂等 | 进度上报、收藏、审核等接口须支持幂等；写接口支持可选 Idempotency-Key 头，同键在 24 小时内返回首次结果 |
| 限流 | 内部接口按用户限流，公开接口按客户端限流；超限返回 42901 |
| 超时 | 内部接口客户端超时 10s，公开接口 5s；上传接口单独放宽至 30 分钟 |
| 追踪 | 请求头透传 traceId，缺失时服务端生成；响应 requestId 与日志一致 |
| 缓存 | 课程目录类查询可使用 ETag；用户相关数据禁止公共缓存 |

## 7.3 关键内部接口要点

#### I-04 课程详情

| 项目 | 内容 |
|---|---|
| 入参 | 路径 courseId；查询参数 withProgress（默认 true，是否返回本人进度） |
| 出参要点 | 课程基本信息（courseId、title、categoryCode、difficulty、estimatedHours、summary、coverUrl、ownerName、status、version、lessonCount、learnerCount）；chapters 数组，每章含 chapterId、title、sortNo、lessons；每个 lesson 含 lessonId、title、lessonType、durationSec、status（本人该课时状态）；progress 对象含 status、progressPercent、completedLessons、lastLearnedAt |
| 约束 | 未发布课程仅责任教师与管理员可访问，其他角色返回 404 而非 403，避免探测；已归档课程返回 status 为 ARCHIVED 且 detail 中标注不可学习；不返回正文与视频地址 |

#### I-06 课时进度上报

| 项目 | 内容 |
|---|---|
| 入参 | 路径 lessonId；体含 courseId、lessonType、positionSec（视频当前位置）、watchedDeltaSec（本次新增有效秒数）、coveragePercent、scrollPercent、dwellDeltaSec、eventType（HEARTBEAT／PAUSE／SEEK／END／LEAVE／ENTER／SCROLL_STOP）、clientSeq（客户端序号）、sessionId |
| 出参要点 | lessonStatus、lessonProgressPercent、courseStatus、courseProgressPercent、completedLessons、isCourseCompleted、serverTime |
| 约束 | 以令牌 userId 为准，忽略体内任何用户字段；同一 sessionId 内 clientSeq 递增，服务端丢弃乱序的旧报文；positionSec 超过视频时长的报文直接拒绝；接口须在 200ms 内返回，完成判定与事件入箱同步完成 |

#### I-18 提交审核

| 项目 | 内容 |
|---|---|
| 入参 | 路径 courseId；体含 changeNote（5～500 字）、expectedLockVersion |
| 出参要点 | status、submittedAt、reviewId、校验结果 problems 数组（未通过时返回全部问题，含问题类型与定位） |
| 约束 | 校验项：基本信息完整、分类有效、至少 1 章 1 课时、全部视频课时转码成功、图文正文非空、封面可访问；任一不通过返回 42201 并返回问题清单；仅 DRAFT、REJECTED 状态可提交 |

#### I-26 审核决定

| 项目 | 内容 |
|---|---|
| 入参 | 路径 courseId；体含 decision（APPROVE／REJECT）、comment（驳回必填）、expectedLockVersion、expectedCourseVersion |
| 出参要点 | courseStatus、courseVersion（通过时递增）、reviewedAt、nextAction |
| 约束 | 乐观锁校验失败返回 40902 并提示重新加载；未认领时禁止提交；通过时同步更新投影表并生成 course.published 事件；操作全程写审计 |

#### I-35 笔记保存

| 项目 | 内容 |
|---|---|
| 入参 | 体含 noteId（更新时）、courseId、lessonId（可空）、content、anchorSec（可空） |
| 出参要点 | noteId、updatedAt、contentLength |
| 约束 | content 长度 1～20000，超出返回 40003；正文按纯文本存储并做基础格式校验，含脚本或非法标签时净化后保存并在响应中提示；单用户单课程笔记上限 200 条 |

#### I-39 获取文件上传凭证

| 项目 | 内容 |
|---|---|
| 入参 | 体含 fileType（IMAGE／VIDEO）、fileName、fileSize、contentType、courseId |
| 出参要点 | uploadUrl（直传地址）、fileId、expiresAt、maxSize、allowedTypes |
| 约束 | 校验类型白名单与大小上限；凭证有效期 30 分钟；视频上传完成后由文件服务回调 I-40 更新转码状态；本平台不中转文件流 |

## 7.4 对外跨平台公开接口

### 7.4.1 鉴权与治理

| 项目 | 规定 |
|---|---|
| 鉴权方式 | OAuth2 客户端凭证模式；调用方以 clientId 与 clientSecret 换取访问令牌，令牌有效期 2 小时 |
| 授权范围 | 按接口粒度授权：open:course:read、open:completion:read、open:profile:read；未授权接口返回 40302 |
| 来源限制 | 支持 IP 白名单；白名单外的调用直接拒绝，不进入业务逻辑 |
| 限流 | 按客户端 QPS 限流，默认 50，可按客户端调整；超限返回 42901 并给出 Retry-After |
| 审计 | 每次调用记录客户端、接口、耗时、结果码、来源 IP；保留 90 天 |
| 数据最小化 | 只返回接口声明字段，禁止返回整表对象；userId 按需返回，不返回昵称与联系方式 |
| 只读 | 本平台不提供任何公开写接口 |

### 7.4.2 OPEN-01 单个完成状态查询

| 项目 | 内容 |
|---|---|
| 方法与路径 | GET /open/v1/course-completions |
| 入参 | userId（必填）、courseId（必填） |
| 出参要点 | userId、courseId、courseTitle、categoryCode、status、progressPercent、completedLessons、totalLessons、completedAt、completedCourseVersion、lastLearnedAt、courseStatus |
| 特殊约定 | 无学习记录返回 status 为 NOT_STARTED，HTTP 200；课程不存在返回 40401；已归档课程返回 courseStatus 为 ARCHIVED，完成状态仍如实返回 |
| 授权范围 | open:completion:read |

### 7.4.3 OPEN-02 批量完成状态查询

| 项目 | 内容 |
|---|---|
| 方法与路径 | POST /open/v1/course-completions:batchQuery |
| 入参 | courseId 或 courseIds（上限 50，二选一）、userIds（上限 200） |
| 出参要点 | items 数组（userId、courseId、status、completedAt、completedCourseVersion）；summary 含 total、completedCount、invalidUserCount、invalidCourseCount |
| 特殊约定 | 单次组合数上限 10000，超出返回 40003；无效 userId 在结果中标记 INVALID_USER 并计入摘要，不影响其他结果；响应时间 P95 ≤ 500ms |
| 授权范围 | open:completion:read |

### 7.4.4 OPEN-03 课程目录与详情

| 项目 | 内容 |
|---|---|
| 方法与路径 | GET /open/v1/courses、GET /open/v1/courses/{courseId} |
| 入参 | 列表：categoryCode、keyword、page、pageSize；详情：courseId |
| 出参要点 | 列表项含 courseId、title、categoryCode、difficulty、estimatedHours、lessonCount、status、publishedAt；详情额外含 chapters 与 lessons（lessonId、title、lessonType、durationSec） |
| 特殊约定 | 仅返回 PUBLISHED 与 ARCHIVED；不返回正文 HTML、视频地址、封面原图以外的媒体；不返回教师联系方式 |
| 授权范围 | open:course:read |

### 7.4.5 OPEN-04 学习概览查询

| 项目 | 内容 |
|---|---|
| 方法与路径 | GET /open/v1/users/{userId}/learning-summary、GET /open/v1/learning-summaries |
| 入参 | 单查：路径 userId；批量：cursor、limit（≤200） |
| 出参要点 | userId、learnedCourseCount、completedCourseCount、totalLearningSeconds、categoryDistribution（数组，含 categoryCode 与 completedCount）、lastLearnedAt、updatedAt |
| 特殊约定 | 与 FR-STU-13 同口径；无记录返回全零对象而非 404；批量使用游标分页，返回 nextCursor |
| 授权范围 | open:profile:read |

## 7.5 错误码

| 错误码 | 名称 | HTTP 状态 | 触发场景 | 调用方处理建议 |
|---|---|---|---|---|
| 0 | OK | 200 | 成功 | — |
| 40001 | PARAM_INVALID | 400 | 参数格式或取值非法 | 修正参数，不重试 |
| 40002 | PARAM_MISSING | 400 | 必填参数缺失 | 修正参数 |
| 40003 | PARAM_OUT_OF_RANGE | 400 | 超出长度、数量或范围限制 | 拆分请求或修正 |
| 40101 | UNAUTHENTICATED | 401 | 未携带令牌 | 重新获取令牌 |
| 40102 | TOKEN_EXPIRED | 401 | 令牌过期 | 静默续期或重新授权 |
| 40103 | TOKEN_INVALID | 401 | 令牌签名或受众校验失败 | 重新授权，不重试原请求 |
| 40301 | FORBIDDEN | 403 | 无接口访问权限 | 检查授权范围 |
| 40302 | SCOPE_NOT_ALLOWED | 403 | 客户端未被授予该范围 | 联系管理员登记 |
| 40303 | RESOURCE_NOT_OWNED | 403 | 访问非本人资源 | 不重试 |
| 40401 | RESOURCE_NOT_FOUND | 404 | 资源不存在或已删除 | 核对标识 |
| 40402 | COURSE_NOT_PUBLISHED | 404 | 课程未发布或已归档 | 提示用户，不重试 |
| 40901 | STATE_CONFLICT | 409 | 当前状态不允许该操作 | 刷新后重试 |
| 40902 | VERSION_CONFLICT | 409 | 乐观锁版本不一致 | 重新加载数据 |
| 40903 | DUPLICATE_OPERATION | 409 | 重复操作（如重复提交审核） | 视为成功或忽略 |
| 41301 | PAYLOAD_TOO_LARGE | 413 | 请求体或文件超过上限 | 压缩或分片 |
| 42201 | CONTENT_INVALID | 422 | 内容校验不通过（含敏感词、格式非法） | 按返回的问题清单修正 |
| 42901 | RATE_LIMITED | 429 | 触发限流 | 按 Retry-After 退避 |
| 50001 | INTERNAL_ERROR | 500 | 服务端未预期异常 | 携带 requestId 反馈，可重试 |
| 50301 | DEPENDENCY_UNAVAILABLE | 503 | 依赖服务（文件、SSO）不可用 | 退避重试 |
| 50302 | EVENT_CHANNEL_UNAVAILABLE | 503 | 事件通道不可用 | 依赖事件的调用方须降级 |

错误码使用纪律：一个码只表达一种原因；不得出现 50001 包裹业务校验失败的情况；面向用户的 message 不得包含内部实现细节。

## 7.6 版本与兼容

| 项目 | 规定 |
|---|---|
| 版本标识 | 路径中携带主版本（/api/v1、/open/v1）；次版本通过响应头与文档标识，不改变路径 |
| 兼容原则 | 只增不删：新增可选字段视为兼容；字段重命名、删除、语义变更视为破坏性变更 |
| 破坏性变更 | 须发布新主版本并保留旧版本至少一个学期；旧版本在停用前 30 天通知全部登记调用方 |
| 字段废弃 | 先标记为 deprecated 并在文档标注替代字段，至少保留一个版本周期后再移除 |
| 契约发布 | 每次发布同步更新 OpenAPI 文档，订阅方可在开发者页查看变更日志 |
| 客户端标识 | 调用方须在请求头携带平台标识，便于按来源统计与问题定位 |
